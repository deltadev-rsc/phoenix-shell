# phoenix-shell
Перерождение моего старого Phoenix Shell из которого вырос OpenDelta. Переписан с C++ на Zig

-----------------------------------------

# Сборка.

Ставим zig:
```
  # For Arch/Artix/EndeavourOS/CachyOS/Garuda/ArchLabs/ArchCraft
  sudo pacman -S zig

  # For Void
  sudo xbps-install -S zig
```

Качаем репозиторий:
```
  git clone https://github.com/deltadev-rsc/phoenix-shell
```

Запускаем сборку:
```
  zig build
```

Запуск бинарника:
```
./zig-out/bin/phoenix_shell
```
